# 3.4.3.2 Activity Diagram — Timetable Generation (GA)

**Process:** Genetic Algorithm timetable generation in `timetable-engine`  
**Entry point:** `POST /api/v1/timetable/generate`

## Activity Diagram

```mermaid
flowchart TD
    Start([Start]) --> Login[Timetable Officer logs in]
    Login --> JWT{JWT valid<br/>via Kong?}
    JWT -->|No| Deny([Access Denied])
    JWT -->|Yes| SelectDept[Select department, semester,<br/>academic year & template]
    SelectDept --> Validate{Required fields<br/>present?}
    Validate -->|No| ShowError[Display validation error]
    ShowError --> SelectDept
    Validate -->|Yes| LoadData[Load courses, rooms,<br/>lecturers, slots & constraints<br/>from PostgreSQL]

    LoadData --> CheckData{Sufficient data<br/>courses, rooms, slots?}
    CheckData -->|No| FailData([Return error:<br/>insufficient data])
    CheckData -->|Yes| LoadBookings[Load cross-department<br/>external bookings]
    LoadBookings --> InitPop[Initialize guided population<br/>respecting availability]

    InitPop --> EvalFitness[Evaluate fitness in parallel<br/>14 hard + 10 soft constraints]
    EvalFitness --> GenLoop{Generation &lt; max<br/>AND fitness &lt; threshold<br/>AND time limit OK?}

    GenLoop -->|Yes| Elitism[Apply elitism — preserve<br/>best chromosomes]
    Elitism --> Select[Tournament selection]
    Select --> Crossover[Crossover — uniform /<br/>two-point / single-point]
    Crossover --> Mutate[Guided mutation with<br/>adaptive mutation rate]
    Mutate --> EvalFitness

    GenLoop -->|No| Stagnation{Stagnation<br/>limit reached?}
    Stagnation -->|Yes| Inject[Inject fresh random<br/>individuals for diversity]
    Inject --> EvalFitness
    Stagnation -->|No| BestChrom[Select best chromosome]

    BestChrom --> ViolReport[Generate violation report]
    ViolReport --> Persist[Persist timetable & entries<br/>to timetable_db]
    Persist --> Display[Display timetable grid<br/>in Vue frontend]
    Display --> End([End])

    style Start fill:#e8f5e9
    style End fill:#e8f5e9
    style Deny fill:#ffebee
    style FailData fill:#ffebee
    style GenLoop fill:#fff3e0
    style EvalFitness fill:#e3f2fd
```

## Key GA Steps (code reference)

| Step | Module | Description |
|------|--------|-------------|
| Load inputs | `timetable_service.py` | Converts DB entities to GA dicts |
| Initialize population | `ga/population.py` | Guided seeding with availability |
| Fitness evaluation | `ga/fitness.py` | H1–H14 hard, S1–S10 soft penalties |
| Evolution loop | `ga/engine.py` | Selection, crossover, mutation, elitism |
| Persist output | `timetable_service.py` | Writes `Timetable` + `TimetableEntry` rows |
